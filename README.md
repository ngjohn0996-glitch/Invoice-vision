# Invoice Automation App
This application automates and simplifies invoice processing.



## Prerequisites
Before using the application, users must have an Akaunting account and at least one created invoice.

👉Click here to create an Akaunting account:https://akaunting.com/



## How to use
1) git clone https://github.com/ngjohn0996-glitch/Invoice-vision.
2) Start the Uvicorn server and React application.
3) Sync your Akaunting account.
4) Upload invoices and run automation.
